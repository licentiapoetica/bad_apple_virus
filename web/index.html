Bad Apple!! but it's windows

Every white pixel in this video is a desktop window: up to 155 of them, moved and resized 30 times a second.

Or let it take over the page

Press Esc to escape. The Konami code (↑↑↓↓←→←→BA) also works anywhere on this page.

Add it to your site

Upload this folder (bad-apple.js, bad-apple.frames.gz, bad-apple.ogg, bad-apple.mp3), then:

<script src="/bad-apple/bad-apple.js" defer></script>

<!-- an embedded player (4:3, fills the width it is given) -->
<bad-apple theme="xp"></bad-apple>

<!-- a button that unleashes it over the whole page -->
<button data-bad-apple="classic">Don't click</button>

<!-- or arm the Konami code -->
<script src="/bad-apple/bad-apple.js" data-konami="breeze" defer></script>

Or with real windows on KDE Plasma

On Plasma 6 (Wayland or X11), a KWin script moves real windows into every frame:

git clone https://github.com/licentiapoetica/bad_apple_virus
cd bad_apple_virus
python3 kde/bad_apple_kde.py --backdrop
